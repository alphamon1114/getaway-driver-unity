# Varco 3D 모델 적용

이 프로젝트는 Varco 계정이나 API에 접속하지 않으며, 모델을 받은 뒤 Unity 프리팹을 연결하는 구조입니다. Varco의 실제 내보내기 형식은 사용 중인 서비스 화면에서 확인하세요. Unity에 직접 임포트할 수 있는 FBX를 권장하며, OBJ 모델은 재질과 텍스처도 함께 관리하세요. GLB/GLTF만 있다면 Blender 등에서 FBX로 변환하거나 별도 Unity importer를 사용해야 합니다. GLB를 Assets에 넣는 것만으로 현재 프로젝트가 읽지는 않습니다.

## 차량 준비

1. 원본 파일, 텍스처, 생성 프롬프트와 모델 버전을 `Assets/Getaway/Art/Varco/` 아래 모델별 폴더로 관리합니다.
2. 빈 GameObject를 만들어 `PlayerCar_Visual`이라고 이름 붙이고 모델을 자식으로 넣습니다.
3. 모델 정면은 로컬 **+Z**, 위는 **+Y**, 차체 중심은 원점 부근으로 맞춥니다. 기준 크기는 폭 1.9m × 길이 4m, 차체 바닥은 로컬 Y -0.5m입니다.
4. 부모는 Position/Rotation 0, Scale 1을 유지합니다. 크기나 축 보정은 모델 자식에서 합니다. 바퀴가 별도 메시여도 이번 버전에서는 시각 장식으로만 사용됩니다.
5. 차량 프리팹에는 Rigidbody, WheelCollider, 운전 스크립트를 넣지 않습니다. 물리와 충돌은 런타임 차량 루트가 담당하며 시각 모델 내부의 Collider/Rigidbody는 자동으로 비활성화·제거됩니다.
6. 이 부모를 Project 창으로 드래그해 프리팹으로 저장합니다.
7. 데모 씬의 `Getaway Systems > WorldBuilder`에서 `Player Visual Prefab`, `Police Visual Prefab`에 각각 연결하고 씬을 저장합니다.
8. 재생 후 전면 방향, 바닥 높이, 카메라 시야를 확인합니다. 바디 크기가 크게 다르면 `WorldBuilder.Car()`의 BoxCollider 크기도 맞춥니다.

동료는 `Crew Visual Prefab`에 연결합니다. 동료의 피벗은 몸 중심, 높이는 약 2m로 맞추세요. 탑승 후 모델이 사라지는 방식이며 차 안 탑승 애니메이션은 포함하지 않습니다.

## 생성 프롬프트 예시

- 플레이어 차량: “1990년대 스타일의 가상 스포츠 세단, 주황색 차체, 게임용 로우 폴리, 브랜드 로고 없음, 바퀴 4개, 차체와 바퀴 구분, PBR 텍스처”
- 경찰 차량: “가상의 도시 경찰 순찰 세단, 흰색과 남색, 빨강 파랑 경광등, 실존 경찰 로고 없음, 게임용 로우 폴리”
- 동료: “범죄 영화 분위기의 가상 성인 캐릭터, 어두운 재킷, 작은 더플백, 중립 자세, 게임용 로우 폴리”

이 프롬프트는 모델 제작 제안이며 실제 생성 결과는 아닙니다. 텍스처가 분홍색으로 보이면 Built-in용 Standard 재질로 바꾸고 텍스처 슬롯을 연결하세요. URP 프로젝트로 옮기는 경우 `WorldBuilder`의 런타임 재질 셰이더도 해당 파이프라인용으로 수정해야 합니다.

## 모델 출처 기록

각 모델 폴더에 `MODEL_NOTES.md`를 추가하고 생성 날짜, Varco 프로젝트/작업 ID, 프롬프트, 원본 파일명, 수정 내역, 사용 조건 확인 내역을 적으세요. API 키·인증 쿠키는 저장하지 않습니다. 프롬프트 변경도 Git 커밋으로 기록하고 FBX·텍스처 같은 큰 바이너리는 설정된 Git LFS로 관리합니다.
